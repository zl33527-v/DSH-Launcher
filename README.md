# DSH启动管家（鲸鱼娘版）v1.0
她来啦！！！
深海女仆专为一键部署／一键启动／一键重启 你的DeepSeek Harness，向你走来！！！

还在被装环境折腾、敲命令行、黑窗口、服务挂着占资源，烦恼吗？

**【DSH启动管家】把麻烦收进一个小窗口**，专为小白制作，无需单独折腾环境和配置，无需任何命令行，一键部署 DeepSeek Harness。

## ✨ 核心功能
- 一键部署（内置node.js环境安装包，大小仅 32MB）
- 一键启动
- 一键重启
- 开机自启
- 托盘常驻（六项菜单）
- 网页关闭即停
- 一键诊断
- 桌面快捷方式
- 自动更新检查
- 安全自检

## 💎 项目亮点
- 深海女仆同款主题
- 单文件运行
- 隐私安全：服务仅绑定 `127.0.0.1`，不会对外暴露
- 安全自检机制
- 完整运行日志留痕
